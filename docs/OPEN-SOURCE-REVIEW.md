This is not a blanket security certification or approval of an app-store release. Do not upload the working folder, historical designer ZIP, private artifacts or SDK/tooling directories. There is no Git repository at the Android workspace root, so there is **no Android commit history available to audit**. - Pinned CI actions to full verified upstream commit IDs, disabled persisted checkout credentials, added source-boundary tests, and added fully redacted Gitleaks working-tree/full-history scans using a checksum-pinned scanner. Dependabot configuration covers Gradle and GitHub Actions. None of this publishes a repository or deploys a service.

## Publication status and limits

1. **License selected.** LICENSE now contains the official, unmodified PolyForm Noncommercial 1.0.0 text, with required copyright attribution in NOTICE. Noncommercial use/modification/distribution are governed by those terms; there is no general copyleft/source-publication requirement. The project is described as source-available. Third-party dependencies retain their own terms.
2. **Artwork decision closed.** Existing assistant artwork remains unchanged by explicit owner instruction. No artwork changes or additional approval task are pending; normal third-party ownership notices remain.
3. **Intentional public attribution remains.** The existing author's name in copyright and the application/package namespace are public attribution, not an API secret. They have not been silently renamed or removed. The source snapshot contains no publisher account inventory; changing attribution/package identity is a separate product decision.
4. **Repository history/publication is a future step.** Use this source-only snapshot, inspect the staged paths, rerun the Git-index and full-history checks, enable GitHub private vulnerability reporting/secret scanning where available, and inspect the actual public file list. Do not import local private archives or SDK directories. No remote repository or visibility setting was changed.
5. **Runtime/platform boundaries remain.** App sandbox/Keystore protection, restricted FileProvider roots, disabled backup, fixed TLS provider endpoints, nonexported capture service, immutable explicit PendingIntents, platform-protected job/tile services and native welcome animation were reviewed. This was not a hostile-app penetration test, codec fuzzer or real-hardware regression. Exported launcher capture is an intentional user-visible shortcut entry point; microphone permission, controls and the foreground-service indicator remain required. Cached audio/transcripts and shared/public exports are not application-encrypted.
